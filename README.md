# Sterling Design Token (STER)

Official repository for the STER token. It is the public reference for STER's on-chain facts: the token, its liquidity pools, the locks on SDV's liquidity and Founders Allocation, and the wallets held by Sterling Design Ventures LLC (SDV).

Last updated: October 2, 2026.
